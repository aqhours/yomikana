# 歌曲导入

## 默认交互

用户给出歌名即可启动添加。助手负责查找素材、核对歌曲版本、准备翻译与语言标注、接入目录及执行非 UI 检查；无需用户逐项指定操作。

1. 先检查现有歌曲，避免重复导入；从当前项目（包括 `lyrics/`、`imports/`）和 `~/Downloads` 按歌曲名称查找已有音频与歌词，兼容日文文件名的 Unicode NFC/NFD 差异。
2. 根据项目曲库与检索结果判断歌手；优先原版录音，排除 Live、伴奏及不同演唱版本。确实无法判断时才询问。
3. 自动获取元数据、Apple Music 封面和逐字歌词；核对艺人、版本、时长、首句和末句时间。遇到登录验证时明确说明，不能靠整体平移把不同版本强行对齐。
4. 用户未提供中文时按本文要求自行翻译，并完成语法分词、假名、罗马音及简洁词义。歌词本可用于修正分行，但不是启动导入的必需材料。
5. 素材齐全后完成接入及非 UI 检查，提供页面入口交由用户验收。添加歌曲不意味着授权部署。

完整音频优先使用本地已有文件或用户明确指定且允许获取整曲的来源。没有可用来源时保留已完成的资料，只请求缺少的音频；不可将 Apple Music 试听片段作为整曲。该约定是助手工作流程，目前不代表已有能独立运行的全自动导入程序。

## 中文翻译要求

用户于 2026-09-12 指定；后续歌曲由助手按以下要求翻译，有用户译文时优先采用用户版本。

1. 优先准确还原原意，不添加原文没有的含义，不刻意拔高或过度文艺化。
2. 在准确的基础上让中文自然、顺畅，避免生硬逐字直译。
3. 保留 Aqours 歌词本身青春、明亮、真挚的感觉，但不要额外渲染情绪。
4. 尽量保持原歌词的分行和语气。
5. 对重复句、关键词和意象保持译法一致。
6. 如果直译和自然表达冲突，优先选择不改变原意的自然中文。

## 分词释义

分词释义保留简洁的中文词义或必要语气提示，不附加连用形、未然形、口语缩约、省略来源、浊音变化等语法推导说明。例如使用「也许」「过于……」「游泳」「即使……也」。

## 资料与导入流程

- 用 `/Users/jiiong/Documents/Mac/qqlyrics --help` 查看歌词脚本；按歌名、歌手、时长核对原版，保存 QRC 与来源元数据。临时网络错误或风控提示时，不因一次失败就要求用户提供歌词：先做其他导入工作，至少间隔 30 秒重试，再失败则至少间隔 60 秒重试，总计最多三次；遇到明确的限流等待时间则优先遵守。持续要求登录或验证时再向用户说明具体阻塞，不密集重试或绕过验证。每次先保存到独立暂存目录，校验成功后再接入，避免覆盖已人工修订的歌词。
- Apple 日区公开查询：`https://itunes.apple.com/search?country=jp&entity=song&term=...`。匹配歌名、艺人、专辑和曲号；`artworkUrl100` 的尺寸可改为 `3000x3000bb.jpg`，下载后检查实际尺寸。`previewUrl` 是试听片段，不用作整曲同步音源。
- 完整音频使用用户已有文件、购买下载或 CD 导出；核对版本、时长及首句起点。
- 根据原文分词并补充假名、罗马音、词义；把中文译文与展示行逐行对应。
- `node scripts/import-qrc.mjs <source.qrc> <destination.yrc> <first-lyric-start-ms>` 转换真实时间轴，检查原始 QRC 是否为脚本支持的 XML 格式。
- 更新 `app/song-data.ts` 与 `app/page.tsx`，按发行日和曲号排序。音频、时间轴放入 `public/audio/`。
- 运行 `npm run covers:optimize` 和 `npm run palette:generate` 更新封面缩略图及背景配色。
- 不主动为 UI 编写单元测试。执行构建、lint 和非 UI 数据检查后，将歌词展示、播放、跳转及逐字高亮交给用户人工验收；禁止使用 Computer Use 或其他浏览器自动化进行 UI 验收，详见 `AGENTS.md`。

资料未齐全时保存在 `imports/<slug>/`；接入播放器前必须取得真实音频和时间轴。

### 网页版与公开 API 的区别

用户反馈网页版 JOOX 能播放并下载。2026-09-21 读取网页公开脚本后确认：`https://music.gdstudio.xyz/js/ajax.js?v=20260801` 的 `sourceNode` 使用网页同域 `https://music.gdstudio.xyz/api.php`；`player.js` 配置 POST，`ajaxUrl` 附带 `s=crc32(urlEncode(id))` 参数。此前测试的是 `https://music-api.gdstudio.xyz/api.php` 的公开 GET 接口，两者不能直接等同。

网页还默认启用 `autosource`，播放失败会调用 `types=autosource` 并更新实际音源；仅凭搜索时选择 JOOX，不能判定最终音频必然来自 JOOX，也不能认定用户此次播放发生了换源。未带网页校验参数直接 POST 同域接口，本次返回 HTTP 401、`Invalid request`，尚未复现用户成功的网页音频请求。此前「不支持音源」和「空链接」结论仅适用于已测试的公开接口，不能推广到网页版或上游平台。
