本次为本地生产构建与资源体积检查，尚未部署；没有测量线上移动网络的 LCP、INP、CLS 或 Lighthouse 分数。下列体积变化不能直接解释为相同百分比的加载时间改善。

| 项目 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 阅读器 JS，gzip | 53,641 B | 6,494 B |
| 阅读器 JS，未压缩 | 162,518 B | 17,303 B |
| 13 张不重复的首页封面总量 | 9,942,599 B | 1,424,092 B |
| 首页立即加载的封面 | 全部 14 张 | 第一张；其余懒加载 |
| 音频完整缓存下载 | 打开歌曲页后 | 首次打开阅读器后 |

阅读器 JS 数据不包括共享框架和 HTML/RSC。当前歌曲的数据随服务端响应传给浏览器，其他歌曲与组装词典不再进入阅读器 JS。14 首歌曲的完整数据在拆分前后逐项比较一致。音频仍采用原有的完整下载与本地缓存策略，首次播放仍需等待下载完成；缓存失败仍回退在线播放。

按用户选择，首页及歌曲页背景保留原始 URL、分辨率与画质；首页背景仍约 2.13 MB。只对小封面生成质量 88 的 WebP：卡片为 640px，播放器为 256px。缩略图是有损压缩，不是原图的无损替代。首页卡片最大约 205 CSS px，播放器封面约 56 CSS px，尺寸覆盖常见高清屏显示需求。
